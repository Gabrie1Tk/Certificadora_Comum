Exercícios Práticos - Aula 04

JavaScript: Persistência com LocalStorage

Exercício 1: Inicializando os Favoritos

No início do seu script, crie uma variável para armazenar os favoritos. Utilize localStorage.getItem('favoritos') para buscar dados salvos anteriormente. Como o LocalStorage só guarda textos (strings), lembre-se de usar JSON.parse() para transformar o texto de volta em um array. Se não houver nada salvo, inicie um array vazio [].

Exercício 2: Lógica de Adicionar e Remover

No evento de clique do botão "Favoritar", pegue o identificador do carro (usando um data-id). Verifique se este ID já existe no array de favoritos (usando includes() ou indexOf()). Se existir, remova-o. Se não existir, adicione-o ao array. Em seguida, salve o array atualizado usando localStorage.setItem() junto com JSON.stringify().

Exercício 3: Atualizando a Interface

Crie uma função que atualiza o visual dos botões (ex: mudando o coração de branco para vermelho ou adicionando uma classe CSS) baseando-se no array de favoritos atual. Lembre-se de chamar essa função tanto quando a página carrega pela primeira vez, quanto toda vez que um usuário clica no botão de favoritar.
