JavaScript: Persistência com LocalStorage

Exercício 1: Inicializando os Favoritos

No início do seu script, crie uma variável para armazenar os favoritos. Utilize localStorage.getItem('favoritos') para buscar dados salvos anteriormente. Como o LocalStorage só guarda textos (strings), lembre-se de usar JSON.parse() para transformar o texto de volta em um array. Se não houver nada salvo, inicie um array vazio [].

Ver Gabarito 
// EXERCÍCIO 1: Inicializando os Favoritos
// Tenta buscar o texto no localStorage. Se existir, converte para array (JSON.parse).
// Se retornar null, inicia um array vazio usando o operador || (ou).
let favoritos = JSON.parse(localStorage.getItem('carrosFavoritos')) || [];

Exercício 2: Lógica de Adicionar e Remover

No evento de clique do botão "Favoritar", pegue o identificador do carro (usando um data-id). Verifique se este ID já existe no array de favoritos (usando includes() ou indexOf()). Se existir, remova-o. Se não existir, adicione-o ao array. Em seguida, salve o array atualizado usando localStorage.setItem() junto com JSON.stringify().

Ver Gabarito 
// Seleciona todos os botões de favoritar
const botoesFavoritar = document.querySelectorAll('.btn-favoritar');

// EXERCÍCIO 2: Lógica de Adicionar e Remover
botoesFavoritar.forEach(botao => {
  botao.addEventListener('click', () => {
    const idCarro = botao.getAttribute('data-id');

    // Verifica a posição do carro no array (-1 significa que não encontrou)
    const index = favoritos.indexOf(idCarro);

    if (index === -1) {
      // Não está nos favoritos, então adicionamos
      favoritos.push(idCarro);
    } else {
      // Já está nos favoritos, então removemos (corta 1 item na posição 'index')
      favoritos.splice(index, 1);
    }

    // Salva o array atualizado no LocalStorage convertendo para texto (JSON.stringify)
    localStorage.setItem('carrosFavoritos', JSON.stringify(favoritos));

    // Atualiza a tela para refletir as mudanças imediatamente
    atualizarInterfaceFavoritos();
  });
});

Exercício 3: Atualizando a Interface

Crie uma função que atualiza o visual dos botões (ex: mudando o coração de branco para vermelho ou adicionando uma classe CSS) baseando-se no array de favoritos atual. Lembre-se de chamar essa função tanto quando a página carrega pela primeira vez, quanto toda vez que um usuário clica no botão de favoritar.

Ver Gabarito 
// EXERCÍCIO 3: Atualizando a Interface
function atualizarInterfaceFavoritos() {
  botoesFavoritar.forEach(botao => {
    const idCarro = botao.getAttribute('data-id');
    
    // Verifica se o ID deste botão está no array de favoritos
    if (favoritos.includes(idCarro)) {
      botao.classList.add('favoritado');
    } else {
      botao.classList.remove('favoritado');
    }
  });
}

// Chama a função logo que a página carrega para pintar os botões corretamente
atualizarInterfaceFavoritos();
