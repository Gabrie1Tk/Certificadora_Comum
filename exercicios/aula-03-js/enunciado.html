JavaScript: Manipulação do DOM e Eventos

Exercício 1: Selecionando Elementos do DOM

No seu arquivo JavaScript, crie variáveis para capturar os elementos necessários para o nosso filtro. Utilize document.querySelectorAll() para selecionar todos os botões de filtro de categoria (ex: Sedan, SUV, Todos) e todos os cartões de carros presentes na página.

Ver Gabarito 
// Exercício 1: Selecionando Elementos do DOM
const botoesFiltro = document.querySelectorAll('.btn-filtro');
const cartoes = document.querySelectorAll('.cartao');

Exercício 2: Escutando Eventos de Clique

Faça um loop (como forEach) sobre os botões capturados no exercício anterior. Para cada botão, adicione um addEventListener('click', funcao). Para testar, faça a função exibir um console.log() com o texto ou o valor do botão clicado.

Ver Gabarito 
// Exercício 2: Escutando Eventos de Clique
botoesFiltro.forEach(botao => {
  botao.addEventListener('click', () => {
    
    // Remove a classe 'ativo' de todos os botões e adiciona no clicado
    botoesFiltro.forEach(btn => btn.classList.remove('ativo'));
    botao.classList.add('ativo');

    // Captura o valor que queremos filtrar a partir do data-attribute do botão
    const categoriaEscolhida = botao.getAttribute('data-filtro');
    
    console.log("Categoria escolhida:", categoriaEscolhida);
  });
});

Exercício 3: Lógica do Filtro em Tempo Real

Dentro do evento de clique, crie a lógica do filtro. Compare a categoria escolhida no botão com um atributo (ex: data-categoria) presente em cada cartão de carro. Se a categoria bater (ou se o botão for "Todos"), mostre o cartão. Caso contrário, oculte-o aplicando uma classe CSS (ex: .oculto { display: none; }).

Ver Gabarito 
// Exercício 3: Lógica do Filtro em Tempo Real
// (Este código vai dentro do evento de clique, logo abaixo da lógica do Exercício 2)

cartoes.forEach(cartao => {
  const categoriaDoCartao = cartao.getAttribute('data-categoria');

  // Se escolheu "todos" ou se a categoria do cartão for igual à escolhida
  if (categoriaEscolhida === 'todos' || categoriaEscolhida === categoriaDoCartao) {
    cartao.classList.remove('oculto'); // Mostra o cartão
  } else {
    cartao.classList.add('oculto'); // Esconde o cartão
  }
});
