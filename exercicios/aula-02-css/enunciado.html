Exercícios Práticos - Aula 02

CSS, Flexbox, Grid e Responsividade

Exercício 1: Alinhamento com Flexbox

Transforme o menu de navegação (criado na aula anterior) em um menu horizontal moderno. No seu arquivo CSS, selecione o contêiner da lista e aplique display: flex;. Utilize propriedades como justify-content: space-between; e align-items: center; para distribuir os itens de forma espaçada e alinhada.

Exercício 2: Catálogo de Carros com CSS Grid

Vamos organizar a exibição dos veículos. Envolva os cartões criados na Aula 01 em uma div principal e aplique display: grid;. Configure as colunas utilizando grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); para criar uma grelha flexível e adicione um respiro entre os itens com gap: 20px;.

Exercício 3: Design Responsivo com Media Queries

Garanta que o seu layout funcione perfeitamente em dispositivos móveis. Crie uma regra @media (max-width: 768px). Dentro dela, ajuste o comportamento do Grid e do Flexbox para que, em telas menores, os cartões e os links de navegação fiquem empilhados em uma única coluna (ex: flex-direction: column;).
